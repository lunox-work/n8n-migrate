# Evaluation bench

Runs each template through gates 1–8 (PLAN Phase 5): n8n 2.47.7 in Docker is the baseline, the migrated folder is run by the runner, and the comparer decides whether both made the same effects. A template stops at its first failed gate.

## Commands

```
node evals/bench/run.mjs [<id>...] [--split dev] [--limit n] [--variants normal,empty,malformed,hostile]
     [--repeats 3] [--model-mode replay|live] [--driver inprocess|claude] [--skill <id,...|all>]
     [--tag <name>] [--reuse-convert <tag>] [--record] [--no-n8n-check] [--diagnose]
node evals/bench/judge.mjs --calibrate <id>[,<id>] [--variant normal]
node evals/bench/summary.mjs [--tag <name>] [--json]
node evals/bench/tls.mjs [host...]          # CA and leaves (made on demand by the bench)
node evals/bench/validate.mjs               # fixtures (FIXTURES.md)
```

`--tag` names a bench run; re-running the same tag resumes from `.work/ledger/<tag>.json`. `held-out` never runs without explicit ids (EXCLUSIONS.md).

## Contract

- **n8n side.** Every call goes to the mock: plain HTTP through the proxy, HTTPS through CONNECT terminated with a leaf the container trusts (`NODE_EXTRA_CA_CERTS`). Model nodes reach the shim through `http://mock:8080/model/<tag>`. A read uses its `http` source; its `n8n` pin is used only without one, or after the node failed on it (`pin-fallback`). A poll trigger with `http` responses polls once instead of being pinned (binary data cannot be pinned). Sources per node are in each row's `stubs`.
- **Credentials.** Every referenced credential gets a dummy; a node that needs one and has none (stripped export) gets its node type's (`credentialsAttached` in the row). Ollama (non-chat), Qdrant and Supabase point at `http://mock:8080` (`via: direct`, matched by path); S3 at the shortest host of the S3 routes; OAuth2 types get a token that never expires. Chat models (OpenAI, Anthropic, Gemini, Ollama, OpenRouter, and the legacy OpenAI node's text and chat resources when the fixture lists them as models) get a per-node credential to the shim.
- **Overlay `env`.** `{NAME: value}`, merged over all of `config/` and set on the n8n container (recreated when it lacks one), with `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`. The runtime keeps `$env` blocked by design, so the overlay's `claude.overrides` carry the same values into the steps that read them.
- **Binary triggers.** Trigger items with `binary` (uploads) are dropped by a pin: a Form Trigger gets a real multipart submission to its production URL (`--via form`; a run that reaches a Form ending page stops in `waiting`, where n8n leaves it until a browser loads the page), any other trigger runs with `--via cli` (a Code node returns the items).
- **Model replies.** The first n8n run of a template variant is live and recorded; later runs replay it. The Claude side gets n8n's reply for the same model node and call index (replay, the default for gates 4–7) and the bench checks that the Claude request asked the same question (gate 4 fails otherwise). A miss falls back to live and is marked. `--model-mode live` answers the Claude side live and sends model-written fields to the judge.
- **Gate 2.** The folder under test is the headless skill run's (`--skill`) or, for budget, plain `convert.mjs` (`drivers.convert` says which). `plainColumn` always holds the plain converter's gate 2 and preflight.
- **Drivers.** The in-process driver runs gates 3–7 (all variants, repeats). The claude driver runs normal and hostile once per template; gates 3, 4 and 6 must pass on both, and `gates.<n>.driver` names the driver. Under `--driver claude` it runs before gate 7; otherwise a template that passes gates 3–7 in process gets it once for gate 8 (`drivers.claudeForGate8`, within the `claude -p` budget). Its `http` steps (PROPOSALS P5) go to a host `mock-server.mjs` with the fixture's `http` routes: `http-preload.mjs`, preloaded into the session's `runtime/runner.mjs` processes only (the Claude Code binary ignores `NODE_OPTIONS`), sends the runner's `fetch` there in absolute form, and the mock's log is the http half of its effects. Each secret the definition names gets a dummy `N2C_SECRET_<NAME>`.
- **Diagnostics** (`--diagnose`): a template that passes preflight but stops at gates 3–6 still gets Contained measured on the hostile fixture (in process, and with the claude driver on normal and hostile). Recorded under `drivers.claudeDiagnostic` and `metrics.diagnostics`; the verdict stays the first failed gate.
- **Effects.** Writes and media calls are matched as multisets by `service.action.target`, then field by field; reads are reported, not gated; a chat or form workflow's answer is a `chat.reply` effect.
- **Form bodies** (P3). The mock decodes `multipart/form-data` into `{field: value}` (`bodyEncoding: "multipart"`; a repeated field as a list; a file part as `{filename, contentType, size, sha256}`). A form body on either side (n8n's decoded one, or a runner request whose `contentType` is multipart) is compared with every field as a string, keys sorted; JSON bodies keep their types.
- **Timezone and run-time timestamps** (P4). The bench's n8n runs with n8n's default timezone, `America/New_York` (`GENERIC_TIMEZONE` and `TZ`; the Schedule Trigger item too), as the runtime does for a template without `settings.timezone`. n8n's clock is not frozen: its `$now`/`$today` read the wall clock, the Claude side's clock is virtual from n8n's `startedAt`. So where a write field, the reply, or a replayed model input differs between the sides, timestamps within ±10 minutes of n8n's `startedAt` are masked on both sides and the field compared again: ISO 8601 (with `T` or a space), `Date#toString`, RFC 1123/2822, en-US `M/D/YYYY, h:mm AM`, long English dates with a time, and 13- or 10-digit epoch numbers. Only the digits are masked (`<run-time:####-##-##T##:##:##.###>`); the shape and any zone or offset stay, so a format or timezone difference still fails. Strings without a zone are read in the template's timezone, never UTC; date-only strings are never masked. Masked fields are listed as `runTimeMasked` (effects) and `input.runTimeMasked` (model calls). Recordings made under UTC whose model requests carry such text were re-recorded.
- **Connector-limited** (PROPOSALS P1). A failure at gates 3–5 (not a preflight refusal) whose cause or detail names a field of a fixture's `connectorGaps` (its distinctive words, singular or plural), on a step that is the gapped read or downstream of it, sets `connectorLimited: true` and `connectorGapsHit`. The bucket stays. `summary.mjs` reports one-shot success overall and without these templates; the connector shapes behind the gaps are unverified (`shape: assumed`).
- **Results row** (`evals/results.jsonl`): `template, commit, skillCommit, reached (9 = all passed), gate, bucket, cause, connectorLimited, connectorGapsHit, detail, gates, drivers, plainColumn, config (with env names and nonPlaceholder overlays), credentialsAttached, stubs, n8nModelModes, logVsFixture, httpAttempt, metrics` (bench wall time, n8n execution time, skill and claude-driver cost and turns, claude -p runs and cost).
- **Buckets:** unmapped node, field map, expression translation, runner bug, skill instruction, flaky model step, bench defect, fixture.
