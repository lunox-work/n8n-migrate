# Connector responses observed 2026-11-18

Read-only calls on the author's account, captured as the PostToolUse hook receives them (`tool_response`, Claude Code 2.1.326) and as the tools answer directly. Shapes only; values in [tests/connector-observed.test.mjs](../../tests/connector-observed.test.mjs) are made up in the same layout.

| Tool                                              | `tool_response`   | Body                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Slack `slack_read_channel`                        | `[{type:"text"}]` | JSON `{messages: "<text>", pagination_info: "<text>"}`. `messages` is one string: `Channel: #x (C..)`, then per message `=== Message[ from Name[ <mail>] (U.. or B..)] at YYYY-MM-DD HH:MM:SS +08 ===`, `Message TS: <ts>`, the text, optional `Files: ...` and `Thread: N replies (latest: ...)` lines. |
| Slack `slack_read_thread`                         | same              | `=== THREAD PARENT MESSAGE ===`, `=== THREAD REPLIES (n total) ===`, `--- Reply i of n ---`; each with `From:`, `Time:`, `Message TS:` lines, then the text.                                                                                                                                             |
| Slack `slack_read_user_profile`                   | same              | `{result: "User ID: ..\nUsername: ..\nDisplay Name: ..\nReal Name: ..\nPronouns:\nTitle:\nEmail:\nOrganization Name:\nPhone:\nStatus:\nTimezone:\nAdmin: No\nOwner: No\nBot: No\nRestricted: No"}`                                                                                                       |
| Slack `slack_send_message`                        | `[{type:"text"}]` | `{message_link, message_context: {message_ts, channel_id}}`; the posted text gains a `*Sent using* Claude` line (a test workspace, a DM to oneself). Reads there matched the layout above (`Channel: DM (D..)`).                                                                                           |
| Drive `search_files`                              | a JSON string     | `{files: [{id, title, mimeType, viewUrl, owner, parentId, createdTime, modifiedTime, fileSize, ...}], nextPageToken}`; no match is `{}`. Query fields: `title` (not `name`: "Unsupported query field: name"), `parentId = '<id>'` (not `in parents`).                                                    |
| Drive `download_file_content`                     | two text blocks   | `[Resource from claude.ai Google Drive at googledrive://file/<id>] Binary content (<mime>, <n> bytes) saved to <path>` and `{id, title, mimeType, content: "(file sent separately)"}`. A spreadsheet's `text/csv` export is its first tab.                                                               |
| Drive `read_file_content`                         | text              | `{fileContent: "<markdown rendering>", title, viewUrl}` (not used by an adapter)                                                                                                                                                                                                                         |
| Notion `notion-search`                            | `[{type:"text"}]` | `{results: [{id, title, url, type, highlight, timestamp, path, verification, parent_data_source_url}], type}`                                                                                                                                                                                            |
| Notion `notion-fetch` (page)                      | same              | `{metadata: {type: "page"}, title, url, text, cover, icon, full_width, path, verification, page_last_edited_at}`; the id is only in `url`                                                                                                                                                                |
| Notion `notion-fetch` (data source)               | same              | `{metadata: {type: "data_source"}, title, url, text: "<data-source ...><data-source-state>{name, schema}</data-source-state>..."}`                                                                                                                                                                       |
| Notion `notion-query-data-sources` (rows)         | same              | `{results: [{<property>: value, "date:<name>:start": .., url}], has_more}`                                                                                                                                                                                                                               |
| Gmail `search_threads`                            | a JSON string     | `{threads: [{id, messageCount, viewUrl, messages: [{id, threadId, sender, toRecipients, addressDisplayNames: [{displayName, emailAddress}], subject, snippet, date, historyId, internalDate, sizeEstimate, labelIds, viewUrl}]}], nextPageToken, resultCountEstimate}`                                   |
| Gmail `get_message`, `get_thread`                 | a JSON string     | one message as above plus `plaintextBody`, `htmlBody`; a thread is `{id, messageCount, messages, viewUrl}`                                                                                                                                                                                               |
| Gmail `list_labels`, `list_drafts`                | a JSON string     | `{labels: [{labelId, name, labelType, labelListVisibility, messageListVisibility, messagesTotal, messagesUnread, threadsTotal, threadsUnread}]}`; no drafts is `{}`                                                                                                                                      |
| Gmail `create_draft`, `get_draft`, `delete_draft` | a JSON string     | `{id, messageId, threadId, viewUrl}`; a draft as a message with `id` = the draft id and `messageId`; delete answers `{}`. The first connection had been authorised with no Gmail scope ("Insufficient scope"); a personal account with all three scopes answered.                                     |

What changed because of it: Slack and Notion text readers (`runtime/src/shapes.mjs`), Claude Code's saved file read back as base64 `content` (`blobValue` in `runtime/src/driver.mjs`), Drive query fields rewritten (`extract: "driveQuery"`, trigger `parentId`), Gmail display names read from the list form (`addressLine` with `names`), label `type` from `labelType`, a created draft's `message` ids.
